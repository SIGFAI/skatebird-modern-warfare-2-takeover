# Modern Warfare 2 Takeover

**skatebird** × Modern Warfare 2 · visual · idea by the team

Bring Modern Warfare 2 into the game in the most visible and funny way. The change shows in the first 30 seconds of play.

> I turned SkateBIRD into Modern Warfare 2: every kickflip fires a rifle volley, and I dropped a tactical nuke on toy soldiers.

## Install

Copy the BepInEx folder from the mod's release folder into your SkateBIRD game folder (BepInEx 5 must be installed). Start the game: toy soldiers appear and every trick you land fires your rifle at them.
